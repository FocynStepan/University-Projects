## 2. Завдання попередньої підготовки

### 2.1. Словник базових англійських термінів (Dictionary) (*)

| Англійський термін | Визначення та переклад |
| :--- | :--- |
| **Shell script** | Скриптовий сценарій — текстовий файл, що містить послідовність команд для автоматичного виконання командною оболонкою ОС. |
| **Shebang (`#!/bin/bash`)** | Спеціальна послідовність символів на початку скрипту (hash-bang), яка вказує системі абсолютний шлях до інтерпретатора, що має виконати цей файл. |
| **Executable (`chmod`)** | Виконуваний — атрибут файлу, що дозволяє запускати його як програму. Команда `chmod +x` додає цей атрибут. |
| **Variables** | Змінні — іменовані області пам'яті у скрипті, які використовуються для збереження та обробки тимчасових даних. |
| **Conditionals** | Умовні конструкції (наприклад, `if-then-else`), що дозволяють скрипту приймати рішення та виконувати різні блоки коду залежно від умов. |
| **Loops** | Цикли (наприклад, `for`, `while`) — керуючі конструкції, які дозволяють багаторазово виконувати один і той самий блок команд. |
| **nano / vim** | Консольні текстові редактори в Linux. `nano` — простий і зручний для новачків, `vim` — потужний інструмент зі складнішою кривою навчання. |

### 2.2. Відповіді на питання попередньої підготовки

**2.1. Охарактеризуйте поняття скриптового сценарію у командній оболонці. (*)**
Скриптовий сценарій (shell script) — це текстовий файл, що об'єднує набір команд термінала, системних викликів, умовних операторів та циклів в єдину програму. Вони дозволяють автоматизувати рутинні задачі адміністратора чи користувача, зменшуючи ймовірність помилок та час на введення однакових команд вручну.

**2.2. Яким чином створюються та редагуються скрипти, що треба зробити щоб запустити скрипт? (*)**
Скрипти створюються та редагуються за допомогою будь-якого текстового редактора (наприклад, `nano script.sh` або `vim script.sh`). Першим рядком зазвичай додають shebang (`#!/bin/bash`). 
Щоб запустити скрипт, спочатку необхідно надати йому права на виконання командою `chmod +x script.sh`. Після цього скрипт можна запустити з поточної директорії командою `./script.sh`.

**2.3. Які основні компоненти материнської плати ви знаєте? (**)**
Основними компонентами материнської плати є:

* Сокет центрального процесора (CPU socket).
* Слоти для модулів оперативної пам'яті (RAM).
* Чіпсет (Chipset - південний/північний мости або єдиний PCH), який керує взаємодією компонентів.
* Слоти розширення (PCI, PCIe) для відеокарт, мережевих та звукових адаптерів.
* Мікросхема постійної пам'яті з прошивкою BIOS/UEFI та батарейка CMOS.
* Роз'єми для підключення накопичувачів (SATA, M.2).
* Контролери та роз'єми вводу/виводу на задній панелі (USB, LAN, Audio).

**2.4. Коротко охарактеризуйте для яких пристроїв оперують поняттями MBR та GPT? (**)**
Цими поняттями оперують для дискових накопичувачів (HDD, SSD, NVMe). Це стандарти розмітки таблиці розділів на диску, які вказують системі, де починаються і закінчуються логічні розділи:
* **MBR (Master Boot Record):** Старий стандарт. Підтримує диски об'ємом не більше 2 ТБ і дозволяє створити максимум 4 основних розділи.
* **GPT (GUID Partition Table):** Сучасний стандарт, що є частиною специфікації UEFI. Підтримує диски гігантських об'ємів (до 9,4 ЗБ) і дозволяє створити до 128 розділів у Windows.

**2.5. В чому суть операції монтування, для чого вона потрібна? (**)**
Монтування — це процес підключення файлової системи фізичного носія (жорсткого диска, флеш-накопичувача, CD/DVD) до єдиного дерева каталогів операційної системи Linux. Вона потрібна для того, щоб ОС і користувач могли отримати доступ до файлів на пристрої. Після підключення флешки система монтує її, наприклад, у папку `/mnt/usb` або `/media/user/`, і всі файли пристрою стають доступними всередині цієї папки.

### 4.3. Власний скриптовий сценарій: Моніторинг вільного місця на диску (\*\*)

```bash
#!/bin/bash
# Цей скрипт перевіряє заповненість кореневого розділу диска (/)
# і виводить попередження, якщо використано більше 80% місця.

THRESHOLD=80
# Отримуємо відсоток використання кореневого розділу, видаляємо символ '%'
USAGE=$(df -h / | awk 'NR==2 {print $5}' | sed 's/%//')

echo "Перевірка використання дискового простору..."
echo "Поточне використання кореневого розділу (/): $USAGE%"

if [ "$USAGE" -ge "$THRESHOLD" ]; then
    echo "⚠️ ПОПЕРЕДЖЕННЯ: Залишилося мало вільного місця на диску! (Використано понад $THRESHOLD%)"
else
    echo "✅ Місця на диску достатньо."
fi

```

## 5\. Відповіді на контрольні запитання

**1. В чому відмінність між командами `arch` та `lscpu`?** Команда `arch` (що є аналогом `uname -m`) виводить лише одну стрічку — базову архітектуру процесора/системи (наприклад, `x86_64` або `aarch64`). Команда `lscpu` зчитує системні дані (з файлу `/proc/cpuinfo`) і виводить розгорнуту інформацію: назву моделі, кількість фізичних і логічних ядер, розмір кешу (L1, L2, L3), тактову частоту, наявність віртуалізації тощо.

**2. Якою командою можна отримати інформацію про стан використання RAM поточною системою?** Найзручнішою командою є `free` (бажано з ключем `-h` для виводу у ГБ/МБ: `free -h`). Вона показує загальний обсяг, використану та вільну оперативну пам'ять, а також пам'ять, що використовується під буфери та кеш. Також можна використати команду `top` або `htop` для моніторингу пам'яті у реальному часі.

**3. Яким чином у скриптах можна опрацьовувати змінні та створювати розгалужені та циклічні сценарії? (\*)** \* **Змінні** оголошуються без пробілів навколо знака рівності: `NAME="Stepan"`. Їх значення отримують, додавши `$` перед ім'ям: `echo $NAME`.

 * **Розгалуження (Conditionals)** реалізуються за допомогою конструкції `if`:
      ```bash
      if [ умова ]; then
         команди
      else
         команди
      fi
      ```
  * **Цикли (Loops)** створюються за допомогою `for` (перебір елементів) або `while` (поки істина):  
    ```bash
    for i in 1 2 3; do
        echo "Цикл $i"
    done
    ```

**4. Які команди для перегляду стану підключення периферійних пристроїв можна використати в терміналі? (\*)** \* `lsusb` — для перегляду пристроїв, підключених через USB-порти.

  * `lspci` — для перегляду пристроїв, підключених до шини PCI/PCIe (відеоадаптери, мережеві карти).
  * `dmesg` — виводить лог повідомлень ядра, де можна побачити в реальному часі подію підключення або відключення периферії (часто використовують разом з `grep`, наприклад `dmesg | grep -i usb`).

**5. Які можливості застосунку `gparted`? (**)\*\* GParted (GNOME Partition Editor) — це потужний графічний застосунок для управління дисковими розділами та файловими системами. Його можливості включають:

  * Створення нових таблиць розділів (MBR, GPT).

  * Створення, видалення, копіювання, переміщення та зміну розміру розділів без втрати даних (наскільки це технічно можливо).

  * Форматування розділів у різні файлові системи (ext4, NTFS, FAT32, btrfs, linux-swap тощо).

  * Перевірка та виправлення помилок у файлових системах.

  * Зміна міток (Label) та прапорців (наприклад, `boot`, `hidden`) дисків.
