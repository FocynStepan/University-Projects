## 2. Завдання попередньої підготовки

### Словник термінів

- **CLI (Command Line Interface)** — інтерфейс командного рядка, який забезпечує точний контроль, високу швидкість та можливість автоматизації завдань.  
- **Shell** — оболонка, інтерпретатор командного рядка.  
- **Prompt** — рядок запрошення термінала.  
- **Command** — команда, програма, що виконує дію.  
- **Option** — параметр (опція), що змінює основну поведінку команди.  
- **Argument** — аргумент, що надає команді додаткову інформацію, з якою треба працювати.  
- **Variable** — змінна, що дозволяє користувачу або оболонці зберігати дані.

### Визначення понять

- **Командний інтерпретатор / Оболонка (Shell):** Програма, яка перекладає введені користувачем команди у дії, що мають бути виконані операційною системою. Найпоширенішою оболонкою для Linux є Bash.  
- **Команда (Command):** Програмне забезпечення, яке при виконанні в CLI виконує певну дію на комп'ютері.

### Відповіді на питання

1. **Яку базову інформацію надає рядок запрошення prompt?**  
   Рядок запрошення зазвичай містить інформацію про ім'я користувача (Username), ім'я системи або хоста (System name) та поточний робочий каталог (Current Directory).

2. **Для чого команді потрібні параметри та аргументи?**  
   Параметри використовуються для модифікації основної поведінки команди, тоді як аргументи надають додаткову інформацію, наприклад, ім'я файлу або каталогу, над яким команда повинна виконати дію.

3. **Яке призначення команди `ls`, які параметри та аргументи вона може мати? Наведіть 3 приклади.**  
   Команда `ls` виводить вміст каталогів.  
   - `ls` — виводить вміст поточного каталогу.  
   - `ls -l` — виводить вміст поточного каталогу у довгому форматі (з детальною інформацією).  
   - `ls /etc/ppp` — виводить вміст конкретного каталогу, переданого як аргумент.

4. **Яким чином можна використати історію команд, які переваги це надає?**  
   Історія команд дозволяє переглядати та повторно виконувати раніше введені команди. Це економить час, зменшує кількість помилок при введенні довгих команд та спрощує роботу в терміналі.

5. **Яке призначення команди `echo`?**  
   Команда `echo` використовується для виведення рядка тексту або значення змінних безпосередньо у термінал.

6. **Охарактеризуйте поняття змінної в оболонці Bash, які типи змінних вона підтримує?**  
   Змінна — це функція, що дозволяє зберігати дані тимчасово в пам'яті для використання оболонкою або користувачем. Оболонка Bash підтримує два типи змінних: локальні (local) та змінні оточення (environment).

7. **Яке призначення команд `env`, `export` та `unset`?**  
   - `env` — виводить список усіх поточних змінних оточення.  
   - `export` — перетворює локальну змінну на змінну оточення, роблячи її доступною для дочірніх процесів.  
   - `unset` — видаляє створену змінну з пам'яті.

8. **Які команди для отримання довідки по командам в терміналі ви знаєте?**  
   Основні команди довідки: `man` (викликає сторінку посібника), `info`, `help` (для вбудованих команд Bash) та використання параметра `--help`.

## 3. Основні позиції ходу роботи

### 3.1. Опис базових команд

| Назва команди | Її призначення та функціональність |
| :--- | :--- |
| `ls` | Виводить інформацію про каталоги та файли. За замовчуванням без аргументів відображає інформацію для поточного каталогу. |
| `ls -l` | Дозволяє відобразити інформацію про файли у довгому форматі з розширеною інформацією. |
| `ls -l /tmp` | Дозволяє відобразити детальну інформацію про файли в каталозі /tmp. |
| `type` | Визначає тип команди (чи це вбудована команда, зовнішня, псевдонім або функція). |
| `cd` | Змінює поточний робочий каталог. |
| `pwd` | Виводить повний шлях до поточного робочого каталогу. |
| `man` | Відкриває інтерактивний посібник (manual) для вказаної команди. |

---

### 3.2. Робота в терміналі (Практичні завдання)

#### 2.1. Робота зі змінними та псевдонімами:

```bash
var_name1="Степан"
var_name2="Олександр"
var_name3="Дмитро"
echo $var_name1 $var_name2 $var_name3

alias mycal1='cal 2005'
alias mycal2='cal 2004'
alias mycal3='cal 2005'
```

#### 2.2. Робота з функціями:

```bash
students_report() {
    echo "$var_name1, $var_name2, $var_name3"
    echo "2005, 2004, 2005"
}
students_report
```

#### 2.3. Робота з лапками:

```bash
echo "We create such variables as \$var_name1, \$var_name2, \$var_name3, which stored our names $var_name1, $var_name2, $var_name3"

echo "We create such Aliases as mycal1, mycal2, mycal3, which can show our calendars: $(mycal1), $(mycal2), $(mycal3)"
```

#### 2.4. Робота з інструкціями керування:

Завдання 2.1 та 2.2 можна виконати через інструкції керування (Control Statements), такі як крапка з комою (`;`). Це дозволяє виконати декілька команд в одному рядку без створення функції:

```bash
echo "$var_name1, $var_name2, $var_name3" ; echo "2005, 2004, 2005"
```

#### 2.5. Робота з командами довідки (`uname`):

1. `uname -a` — виводить усю доступну системну інформацію  
2. `uname -s` — виводить ім'я ядра  
3. `uname -r` — виводить реліз ядра  
4. `uname -v` — виводить версію ядра  
5. `uname -m` — виводить апаратну архітектуру машини

## 4. Відповіді на контрольні запитання

1. **Які типи команд існують в оболонці Bash?**  
   В оболонці існують: внутрішні (вбудовані в саму оболонку), зовнішні (зберігаються у файлах), псевдоніми (aliases) та функції.

2. **Що таке змінні оточення? Які вони бувають. Як їх можна переглянути в терміналі?**  
   Змінні оточення — це змінні, які доступні для всієї системи та всіх дочірніх процесів, запущених в оболонці. Вони містять критичну системну інформацію. Їх можна переглянути командою `env` або `printenv`.

3. **Опишіть змінну `$PS1`. Як в терміналі переглянути її вміст?**  
   Змінна `$PS1` відповідає за формат відображення основного рядка запрошення (prompt) у терміналі. Переглянути її вміст можна командою: `echo $PS1`.

4. **Як можна змінити значення змінної `$PS1`? Що при цьому відбудеться в рядку запрошення в bash. Як змінити значення цієї змінної не на поточний сеанс, а за замовчуванням?**  
   Значення можна змінити, наприклад, командою: `PS1="\u@\h:\w$ "`. Після цього зовнішній вигляд запрошення одразу зміниться згідно з новими параметрами. Щоб змінити значення за замовчуванням (назавжди), потрібно додати рядок з новим значенням змінної у файл конфігурації `~/.bashrc`.

5. **Для чого використовують лапки в оболонці Bash?**  
   Лапки повідомляють системі, що інформацію всередині них слід ігнорувати як спеціальні символи або обробляти інакше, ніж зазвичай. Одинарні лапки (`'`) ігнорують усі спеціальні символи, подвійні (`"`) дозволяють підставляти значення змінних, а зворотні (```) виконують команду всередині.

6. **Для чого використовують інструкції керування, які їх види Ви знаєте?**  
   Інструкції керування дозволяють використовувати кілька команд одночасно або запускати додаткові команди за певних умов. Види: крапка з комою (`;`), подвійний амперсанд (`&&`) та подвійна вертикальна риса (`||`).

7. **В чому різниця якщо в кінці рядку запрошення bash стоїть символ `$` чи `#`?**  
   Символ `$` означає, що термінал працює від імені звичайного користувача (з обмеженими правами). Символ `#` означає, що термінал працює від імені суперкористувача (`root`), який має повні адміністративні права в системі.

8. **Яке призначення команд `whereis` та `locate`? Яка між ними відмінність?**  
   `whereis` шукає розташування бінарних файлів, вихідних кодів та сторінок посібника (man) для конкретної команди в стандартних каталогах системи. `locate` здійснює швидкий пошук будь-яких файлів та каталогів по всій файловій системі, використовуючи попередньо проіндексовану базу даних.
